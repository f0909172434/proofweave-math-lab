# Recommend model prompt

Use the current model inventory, classification, user/provider/privacy policy, independent benchmark data and budget. First exclude unavailable/unverified-unapproved, deprecated, forbidden, tool/context-deficient and privacy-incompatible candidates.

Score capability, benchmark, tools, context, reliability and independence minus cost, latency, deprecation, availability and correlation risks. Map effort only to supported settings.

Return selected/rejected candidates, tier, requested/effective effort, control method, cost/latency, fallback, escalation, independence and inventory version. Do not claim execution or silently replace a requested unavailable model.

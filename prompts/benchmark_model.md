# Benchmark model prompt

Use a fixed-version suite with public/hidden separation and an answer key independently reviewed by someone other than the evaluated model.

Record provider/model/snapshot/effort/prompt/tools, correctness, false acceptance/rejection, timeout/failure, cost and latency for every case. The verifier profile prioritizes false acceptance.

Do not run a paid call without explicit authorization. Do not discard failures or emit a precise ranking when samples, categories or independent keys are insufficient.

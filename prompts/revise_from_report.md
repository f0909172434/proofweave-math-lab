# Revise from report prompt

Read the frozen referee report and issue ledger. Build an owner/status plan using OPEN, IN_PROGRESS, FIXED, REJECTED or DEFERRED.

For each accepted issue link original location, affected facts, changed files, new/revoked facts, experiments to rerun and sections to re-review. Propagate fact changes to every descendant. Mathematical changes require independent re-verification and full-paper re-audit.

Return updated artifacts, issue transitions, revision summary and response-to-reviewers draft. Do not claim an issue fixed without its required verification.

# Audit references prompt

For each citation open the primary/publisher/official source. Verify author, title, date, venue, version, DOI/arXiv, theorem/section/page and license/access constraints.

Quote no more than necessary. Record the exact manuscript sentence and whether the source entails it under the same assumptions. Search for retractions, corrections, conflicts and a published version of preprints.

Return VERIFIED, CONFLICT, RETRACTED or UNCERTAIN source records. A DOI, metadata match or search snippet alone is insufficient.

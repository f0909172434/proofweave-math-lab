# Generate seed ideas prompt

Use workflow 03 and the current formalized target. Generate three to five genuinely different routes: direct proof, alternative theory, obstruction/counterexample, and toy/special case at minimum.

For each route give prerequisites, candidate local claims, required VERIFIED facts/sources/tools, main risk, falsification test, measurable milestone, stop condition and cost estimate. Identify dependencies so only independent routes are parallelized.

Do not vote on truth, fill proof gaps or label any route VERIFIED. Return a ranked research portfolio by tractability/risk, with the ranking rationale.

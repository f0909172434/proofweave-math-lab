# Classify task prompt

Classify a versioned task using type/domain, proof depth, novelty, error cost, verification importance, context, tools, dependencies, ambiguity, adversarial risk, latency, cost and privacy. Do not infer difficulty from length alone.

Return complexity_score and risk_score (0–100), capability tier, abstract reasoning profile, required tools, independence requirement, fallback policy and concise justification. Mark UNKNOWN rather than guessing missing host/model data.

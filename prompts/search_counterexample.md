# Search counterexample prompt

Restate the universal claim and every hypothesis. Search systematically through weakest hypotheses, endpoints, degenerate parameters, low dimension, finite/toy models, symmetric/extreme cases and symbolic/numerical/random candidates.

For every candidate verify all hypotheses exactly and distinguish mathematical violation from floating/implementation error. Save reproducible code/config/data when computation is used.

Return a validated refutation claim with the smallest witness, or a bounded negative-search report. “No counterexample found” is not proof.

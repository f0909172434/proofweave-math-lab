# Toy workflow: sum of the first odd integers

This directory is isolated from the real research state. It demonstrates:

1. a precise integer theorem with an explicit empty-sum convention;
2. a complete induction proof accepted by a cold-start verifier packet;
3. a deliberately gap-filled asymptotic argument rejected by the verifier;
4. verifier-only promotion into the toy fact graph;
5. LaTeX claim mapping and compilation.

Run from the repository root:

```powershell
python scripts/run_toy_workflow.py
```

The verifier decisions are fixed demonstration fixtures, not evidence that an
AI autonomously proved or reviewed the theorem during installation.
